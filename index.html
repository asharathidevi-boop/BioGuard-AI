How BioGuard AI Continuous Learning Works (4 Clear Stages)

1. Feedback Collection

Captures the original leaf image, Teachable Machine prediction, confidence score, and your verified label without altering the original scan.

2. Saved Correction Memory

Stores full image blobs and labels locally in browser IndexedDB. If the same image is re-uploaded, the saved correction is shown as a reference without blindly overriding new scans.

3. Future Training Dataset Export

Exports verified images and structured JSON/CSV annotations grouped by class folder name for model training.

4. Model Retraining & Replacement

Browser storage does not directly retrain the hosted Teachable Machine cloud model (B-SoEzTPH). Upload exported images into Google Teachable Machine, retrain, and update the model URL.
